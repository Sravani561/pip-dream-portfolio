# Pip the Skull Baby — Dream Portfolio

A responsive, playful portfolio for Pip, Junior Dream Engineer at Midnight Nursery.

## Run locally
1. Extract the ZIP.
2. Open the `pip-portfolio` folder in Visual Studio Code.
3. Open `index.html` with Live Server, or double-click `index.html` to open it in a browser.

## Included
- Pip's dream-world moodboard and character artwork
- Individual friend cards for Nib, Tinkle, and Doz
- Responsive layout for desktop and mobile
- Day/night mode, sound controls, generated lullaby and baby coo, cursor reactions, hidden interactions, and Chaos Mode already included in the page
- Accessible labels and reduced-motion handling for the friend cards

## Assets
Images are in `images/`; friend crops are in `images/friends/`.

Audio is generated in the browser with Web Audio; no external audio file is required. Google Fonts are loaded online, with local system fallbacks.
