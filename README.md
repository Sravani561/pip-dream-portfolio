# 🌙 Pip Dream Portfolio

A creative and interactive dream-themed website designed to provide visitors with a magical and memorable experience.

## 🔗 Live Demo

[Visit Pip Dream Portfolio](https://sravani561.github.io/pip-dream-portfolio/)

## ✨ Features

- 🌙 Dream-themed design
- 🎨 Clean and engaging user interface
- 💭 **Order a Dream** section with imaginative dream ideas
- ✨ Interactive website elements and animations
- 📱 Designed for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Sravani561/pip-dream-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd pip-dream-portfolio
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
